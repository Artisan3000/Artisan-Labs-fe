# Contributing

## Start

- [ ] Read `ARCHITECTURE.md`, `REPO_BOUNDARY.md`, and the feature brief.
- [ ] Branch from the agreed Artisan Labs FE commit.
- [ ] Extend existing routes, components, auth, and integrations.

## Rules

- Production implementation must arrive through an Artisan Labs FE branch and PR.
- Do not deliver a disconnected prototype for Brian to reconstruct.
- Do not add or replace login, auth, sessions, users, databases, schemas, or integration contracts without an accepted decision.
- Label mocks, fallbacks, preview-only paths, incomplete behavior, and assumptions.
- Do not claim production enablement when it is unverified.
- Keep each PR to one approved scope.

## Done

- [ ] Acceptance criteria pass in this repository.
- [ ] Build, typecheck, lint, and relevant tests pass, or exceptions are explained.
- [ ] Changed flows and failure states are verified.
- [ ] Environment variables, dependencies, SQL, risks, and operating steps are documented.
- [ ] `HANDOFF_CHECKLIST.md` is complete.
