# Careers MVP Handoff Checklist

- [ ] Includes only T99 and resources/policies unless added scope is approved.
- [ ] Uses an Artisan Labs FE branch from the agreed base commit.
- [ ] Lists every changed file, route, and dependency.
- [ ] Lists environment variables and configuration.
- [ ] Separates production code, mock data, and incomplete behavior.
- [ ] Supplies SQL as a migration proposal, not approved production schema.
- [ ] Documents identifiers used and any future Academy-linking assumption.
- [ ] Does not add or replace login, auth, users, sessions, or Academy integration.
- [ ] Includes setup, build, typecheck, lint, test, and verification results.
- [ ] Includes screenshots or a short demo.
- [ ] Lists integration risks, conflicts, and remaining work.
- [ ] Excludes checklists, meeting tools, account creation, and other prototype modules.
