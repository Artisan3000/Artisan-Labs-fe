# AI Collaboration Guide

## Load Before Work

- `ARCHITECTURE.md`
- `REPO_BOUNDARY.md`
- The approved feature brief
- Relevant Artisan code
- Academy references only when identity or Academy data is involved

## Rules

- Preserve repository ownership boundaries.
- Extend existing systems; do not generate replacement auth, users, data, or integrations.
- Do not invent APIs, schemas, credentials, requirements, or deployment state.
- Stop when uncertainty affects identity, permissions, HR data, schema, migration, or rollout.
- Label assumptions `Assumption` and gaps `Unclear — confirm with team`.
- Keep work inside the approved scope and Artisan branch.
- Review output for repository fit, security, failure handling, and maintenance.

Reject output that adds SSO to the current MVP, copies Academy systems, imports excluded prototype modules, or leaves integration discovery to Brian.
